## ✨ Features

- 🧠 **Reverse AI Search:** Can't remember a word? Describe the concept, and our AI will find the exact word you're looking for instantly.
- 📚 **Comprehensive Dictionary:** Lightning-fast definitions, synonyms, and antonyms.
- 💾 **Offline Vault:** Save your favorite words and access them anytime in your Personal Vault.
- 🎨 **Dynamic Theming:** Deeply integrated Material 3 design. Choose between System Default, Warm Light, and Modern Dark mode.
- 🔄 **Automated OTA Updates:** Seamlessly download and install new versions directly inside the app using automated GitHub Releases.
- 📱 **Fluid Animations:** Beautiful `AnimatedVisibility` transitions, nested scrolling, and edge-to-edge UI.

## 🚀 Installation & Setup

1. **Download the APK:** Head over to the [Releases](../../releases/latest) page and download the latest `app-debug.apk` file.
2. **Install:** Open the file on your Android device. You may need to enable "Install from Unknown Sources" in your settings.
3. **Configure API:** Open the **Settings** tab in the app and paste your [OpenRouter API Key](https://openrouter.ai) to unlock the AI features.

### 🔄 Seamless OTA Updates
LexiVerse features a built-in updater connected directly to GitHub Actions! When a new version is pushed to the `main` branch, a GitHub Release is automatically drafted. The app will detect this, alert you, and let you install the update with a single tap.

## 🛠️ Tech Stack

*   **Language:** [Kotlin](https://kotlinlang.org/)
*   **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material Design 3)
*   **Architecture:** MVVM (Model-View-ViewModel) with Clean Architecture principles
*   **Networking:** Retrofit + OkHttp
*   **Local Storage:** DataStore Preferences
*   **AI Integration:** OpenRouter API
